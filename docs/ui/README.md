940 pixels, generated by the processor integration tests on Linux. They are

To regenerate from a full native build, run CTest with the absolute output
directory in `FRESHLAB_SNAPSHOT_DIR`. For example, in a Unix shell:

```bash
FRESHLAB_SNAPSHOT_DIR="$PWD/docs/ui" ctest --test-dir build -C Release --output-on-failure
python scripts/make_previews.py --build-dir build
```

On headless Linux, prefix the CTest command with `xvfb-run -a env`.
In PowerShell, set `$env:FRESHLAB_SNAPSHOT_DIR = "$PWD/docs/ui"` before CTest.
The audio script accepts core-only builds too (`--build-dir build-core`).
It concatenates the committed WAVs without regenerating or changing them.
